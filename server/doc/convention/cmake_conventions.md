## CMake Conventions
### File Names
- **Cmake files (modules)**: `PascalCase.cmake`
- **Project CMakeLists**: Always `CMakeLists.txt`

### Function Names
- **Functions**: `snake_case`

### Macro Names
- **Macros**: `UPPER_SNAKE_CASE`

### Variable Names
- **Regular variables**: `snake_case`
- **Cache variables**: `UPPER_SNAKE_CASE`
- **Property names**: `UPPER_SNAKE_CASE`

### Library/Target Names
- **Library names**: `snake_case`
  - Namespace targets with `::`
- **Executable names**: `lowercase`

### Option Names
- **Options**: `UPPER_SNAKE_CASE`
